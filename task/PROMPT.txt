为本地安全响应编写泄露凭据轮换计划验证器，输入为合成凭据、明确暴露记录、凭据衍生关系、服务使用清单与可用替代凭据。每条衍生边给是否继承原凭据被暴露后的风险，风险传播严格按有向边，凭据用途固定到租户与角色。禁止连接服务或读取真实凭据。本题输出撤销和替换计划及证据，不执行实际改动。

替换操作可原子迁移一个服务的若干权限绑定，撤销操作仅使确切代数失效；多服务可能共用一凭据。每个服务在任意中间状态都要维持各角色要求的最少可用凭据数，每项受影响的真实凭据代数须在截止步前撤销，替代凭据在配置步区间内可用。还要满足独立保管域隔离，同一服务的两个敏感角色不得绑定同保管域。最多 12 个服务、18 项候选动作，求最少总风险成本的完整序列，再按序列长度、动作 ID 序列定序。

输出每步活跃服务绑定、暴露传播路径和覆盖检查；无解给出撤销风险覆盖最高的可达状态及各下一步阻断的具体证据。用小规模独立穷举核对，覆盖撤销单独可行却无法组合、已暴露衍生凭据不可作为替代、非贪心的跨服务换绑、跨租户同凭据名及输入换序稳定。

在 Windows 原生 Python 3.12、标准库和 CPU 环境下实现，全部输入自行合成，离线测试。交付源码、README、可重放 cases.json 和自动化测试。提供 python -m solution --input cases.json --output result.json 与 python -m unittest discover -s tests -v。测试须断言具体结果，README 写明规则、输入输出、错误码和实测结果。
